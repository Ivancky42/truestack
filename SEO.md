# Truestack SEO Guide

## Implemented Improvements

### 1. Sitemap (`/sitemap.xml`)
- Dynamic sitemap listing all public pages
- Proper priority and changeFrequency for crawler guidance
- Set `NEXT_PUBLIC_SITE_URL` in production (e.g. `https://www.truestack.my`)

### 2. Robots.txt (`/robots.txt`)
- Allows all crawlers
- Points to sitemap
- Disallows `/api/` if present

### 3. JSON-LD Organization Schema
- Schema.org Organization markup for Google Knowledge Graph
- Includes: name, description, contact point, logo, area served, expertise
- Validate at validator.schema.org or Google Rich Results Test

### 4. metadataBase
- Ensures absolute URLs for OG images and canonical links
- Uses `NEXT_PUBLIC_SITE_URL` or falls back to `https://www.truestack.my` (apex `truestack.my` is normalized to www)

### 5. Expanded Keywords
- Primary: KPKT license Malaysia, KPKT account management, money lender Malaysia
- Product: e-KYC Malaysia, TrueIdentity, TrueKredit
- Supporting: P2P lending platform Malaysia, PDPA compliant KYC, Lampiran A/B1

## Google Knowledge Panel

Knowledge Panels are automatically generated by Google. You cannot request one directly. They appear when Google has enough signals about your entity.

### Implemented on-site
- JSON-LD Organization schema on every page (`components/seo/organization-schema.tsx`)
- `name` / `legalName`: Truestack Technologies / Truestack Technologies Sdn. Bhd.
- Square `logo` ImageObject (`/truestack-favicon.png`, 250×250)
- KL Trillion `address`, E.164 `telephone`, `email`, SSM registration `identifier`
- `sameAs`: verified Crunchbase, LinkedIn, GitHub, and Capterra profiles (`lib/seo-defaults.ts` `orgSameAs`); add further live listings (e.g. Wikidata) via `NEXT_PUBLIC_ORG_SAME_AS`

### What still helps off-site
1. Google Business Profile for the KL Trillion office
2. Wikidata item (cite SSM + the website), then add the Q-ID URL to `NEXT_PUBLIC_ORG_SAME_AS`
3. Crunchbase / press coverage using the legal name
4. Consistent NAP (name, address, phone) everywhere

### Claiming an existing panel
1. Search "Truestack Technologies" on Google
2. If a panel appears, click "Claim this knowledge panel"
3. Verify via Search Console (or YouTube / X / Facebook)

## Locale SEO (en / ms / zh / ru)

English is unprefixed. Bahasa Malaysia is `/ms`, Simplified Chinese is `/zh`, Russian is `/ru`.

### hreflang

Every indexable localized page emits the same alternate set from `hreflangAlternates` in `lib/i18n/config.ts` (page `<head>` and sitemap `<xhtml:link>`):

| Key | URL |
|---|---|
| `en` | English (unprefixed) |
| `ms` | `/ms/...` |
| `zh-Hans` | `/zh/...` |
| `zh-CN` | `/zh/...` (same URL; mainland-China / Baidu signal) |
| `ru` | `/ru/...` |
| `x-default` | English |

Each locale has a **self-canonical** (`/zh/truekredit` canonicalises to `/zh/truekredit`, not the English URL). Legal pages (privacy, terms, PDPA, cybersecurity) are English-only: `noindex` on `/ms`, `/zh` and `/ru`, canonical to English. Insights locale URLs are indexable with a self-canonical; article bodies stay English.

### Sitemap

`app/sitemap.ts` lists en + ms + zh + ru for every marketing route, including Insights index and every published insight slug. Legal pages stay English-only. Priority and `changeFrequency` match across locale variants of the same path.

### `og:locale`

| Locale | `og:locale` | `og:locale:alternate` |
|---|---|---|
| en | `en_MY` (Malaysian / British English — not `en_US`) | `ms_MY`, `zh_CN`, `ru_RU` |
| ms | `ms_MY` | `en_MY`, `zh_CN`, `ru_RU` |
| zh | `zh_CN` | `en_MY`, `ms_MY`, `ru_RU` |
| ru | `ru_RU` | `en_MY`, `ms_MY`, `zh_CN` |

### Mandarin targeting

`/zh` commercial metadata is written for China-based operators and investors expanding fintech / money lending into Malaysia (KPKT 放贷牌照 / 现金贷牌照, e-Lending, 牌照续期, 贷款管理系统). See `docs/I18N.md` § Mandarin SEO. Do not invent licence outcomes, capital rules, or timelines.

### JSON-LD languages

Organization `ContactPoint.availableLanguage` and WebSite `availableLanguage` list English (`en`), Malay (`ms`), Chinese (`zh-CN`), and Russian (`ru`).
